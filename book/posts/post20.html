통계로 검증한 9칸 (3) — 신호 성적이 말하는 것

데이터가 확실히 말하는 것은 “하락장에서는 사지 말라” 하나다.

표 2가 말하는 것

  1. 하락장의 매수 신호는 일관되게 나빴습니다. 눌림 후 돌파(−2.6%)·박스 돌파(−1.3%)·회복 확인(−1.2%)은 두 기간 모두 마이너스였고 손익비도 가장 낮았습니다. → CASE 7·8·9를 관찰 칸으로 둔 근거.
  2. 상승장이라고 더 좋지는 않았습니다. 같은 신호의 성적은 상승장과 횡보장이 비슷했고, 횡보장의 눌림 후 돌파(+0.9%)와 지수 20일선 위의 박스 돌파(+1.0%)가 숫자로는 가장 높았지만, 상승장과의 차이는 통계적으로 구분되지 않았습니다.
  3. 허용된 매수 전체(3,571건)의 평균은 +0.5%(이긴 비율 29.1%, 이길 때 +16.9% / 질 때 −6.2%, 손익비 2.73), 두 기간 +0.2% / +1.0%입니다. 이 평균의 95% 범위는 −0.4%~+1.4%로 0을 포함합니다. 한 건 한 건은 거의 본전이고, 차이는 계좌 전체에서 납니다.
  4. 박스 바닥 반등은 이긴 비율 45%로 가장 높지만 평균은 세 장세 모두 마이너스였습니다. → CASE 5 바닥 매수를 연습용으로 둔 근거.
  5. 회복 확인 신호도 평균이 0% 아래였습니다(상승장 −1.3%). 관찰 칸에서 “회복을 확인하고 사는” 방법을 규칙으로 두지 않은 이유입니다.

통계적으로 확실한 것과 아닌 것

(평균의 95% 범위, 같은 달 매매를 한 묶음으로 다시 뽑는 부트스트랩 3,000회)

확실함 - 하락장의 눌림 후 돌파: 평균 −2.6%, 범위 −4.4%~−0.5% (0보다 확실히 나쁨) - 횡보장 눌림 돌파가 하락장보다 나음: 차이 +3.4%, 범위 +1.0%~+5.8%

확실하지 않음 - 허용된 매수 전체 +0.5% (−0.4%~+1.4%) - 횡보장과 상승장의 눌림 돌파 차이 +0.7% (−1.1%~+2.6%) - 횡보장 박스 돌파 지수 위 +1.0% (−0.5%~+2.8%) / 아래 −0.8% (−2.0%~+0.5%)
